GroundControl calculates EU261 flight-delay rights and drafts claims with official sources.
This Space runs only in offline replay mode, with no API keys.
It replays real recorded Nemotron (Nebius Token Factory) and Tavily calls for five synthetic flights.
Choose a recorded flight to explore the calculation, source checks, and draft letters.
Free-text analysis needs live mode and local keys; see the main repository README.
Nothing is sent to airlines or authorities.
